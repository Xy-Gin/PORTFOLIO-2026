# Gianni Automazioni

Sito statico con quattro ascensori interattivi: siti web, software intelligenti, gestione social e messaggio animato con due operai.

## File

- `index.html`: schermata principale.
- `azienda.html`: pagina aziendale con campi compilabili.
- `clone.js`: interazioni e animazioni.
- `interactions.css`: personalizzazioni e stili delle animazioni.
- `original.css`: impaginazione e materiali recuperati dal progetto Framer.
- `analytics.js`: registro locale delle attività, senza invio a server.
- `fonts.css` e `fonts/`: font Inter inclusi nel progetto.

## Utilizzo

Aprire `index.html` nel browser oppure servire la cartella con un server statico. Non occorrono installazione o compilazione.

## Dati aziendali e attività

I testi salvati nella seconda schermata e il registro delle attività rimangono nello spazio locale del browser; non vengono scritti nei file del repository. Il registro non contiene i testi compilati, le foto o i video.

Il pulsante «Scarica il sito compilato» è disponibile nella versione HTML autonoma consegnata separatamente. Per pubblicare i dati aziendali nel sito a più file, modificare i campi `data-company-field` in `azienda.html`.

## Contatti

I collegamenti a telefono, WhatsApp e videochiamata sono in `index.html`. Modificarli nello stesso file per aggiornare le destinazioni.

Il caricamento del repository non attiva automaticamente GitHub Pages.
